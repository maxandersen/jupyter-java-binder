## Why Remove Build Artifacts?

These files are **automatically generated** during the build process:

1. **`lib/`** - Generated by `tsc` (TypeScript compiler)
2. **`labextension/`** - Generated by `jupyter labextension build`
3. **`tsconfig.tsbuildinfo`** - TypeScript incremental build cache

They should **NOT** be in version control because:
- They change every build
- They can be regenerated from source
- They're already in `.gitignore`
- They bloat the repository

## What Happens on MyBinder?

When MyBinder builds, the `postBuild` script will:

1. Run `npm install` - Installs dependencies
2. Run `npm run build:prod` - Regenerates `lib/` and `labextension/`
3. Run `pip install -e .` - Installs Python package
4. Run `jupyter labextension develop` - Links extension
5. Run `jupyter lab build` - Builds JupyterLab with extension

All the deleted files will be **regenerated automatically** during this process!
